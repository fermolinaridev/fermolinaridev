## 🔵 Projetos em destaque

### 💰 [API de Controle Financeiro](https://github.com/fermolinaridev/API-de-controle-financeiro)

Aplicação **full-stack** para gestão de finanças pessoais. Backend em Spring Boot com autenticação JWT completa — *refresh token de uso único com rotação*, logout revogável via blacklist com `jti` e job de limpeza horário. Frontend em React + TypeScript com dashboard, gráficos e filtros combináveis. Importação de extrato em CSV, migrations com Flyway, Swagger, Docker Compose e CI no GitHub Actions.

### 🤖 [JARVIS FULL LOCAL](https://github.com/fermolinaridev/JARVIS-FULL-LOCAL)

Assistente pessoal rodando **100% na sua máquina** — sem API paga, sem nuvem. Python + Ollama com *tool calling nativo*: o modelo decide sozinho quando abrir um app, ler o status do sistema ou salvar um compromisso. Voz clonada localmente via Coqui XTTS-v2 em PT-BR, reconhecimento de fala, detecção de palmas e um HUD estilo Iron Man feito em CSS puro.

### 🃏 [SmartDeck](https://github.com/fermolinaridev/SmartDeck)

Flashcards gerados por **IA** a partir de um tema, texto colado ou PDF. Implementa o algoritmo **SM-2** completo (a mesma base do Anki), recalculando fator de facilidade, intervalo e data de revisão a cada resposta — o deck se adapta ao seu desempenho. Frontend em React + Tailwind com modo de estudo animado, atalhos de teclado e preferências persistidas por usuário.

### ♿ [AdaptaProvas](https://github.com/fermolinaridev/adapta-provas)

Adapta provas escolares para estudantes com **TDAH, TEA, dislexia, Síndrome de Down** e deficiência intelectual leve — cada perfil escalonável em 5 graus de intensidade. CLI em **C99 puro**, sem dependência externa nenhuma, com parser que detecta questões em texto livre colado de PDF/Word. Tem também um porte web em vanilla JS que roda inteiro no navegador: nada sai da máquina do usuário.

### 🧮 [Álgebra Linear Agent](https://github.com/fermolinaridev/algebra_linear)

Agente em Python que resolve problemas de álgebra linear a partir de **linguagem natural**. Cálculo simbólico com `sympy` e fallback numérico em `numpy`, arquitetura modular (parser, solvers, análise, validador) e explicação passo a passo do raciocínio. Cobre decomposições LU/QR/Cholesky/SVD, espaços fundamentais, Gram–Schmidt e métodos iterativos.
